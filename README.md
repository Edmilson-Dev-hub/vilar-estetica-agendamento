# Sistema de Agendamento — Clínica Estética

Trabalho de Conclusão de Curso (TCC) do curso de **Análise e Desenvolvimento de Software** — UNINASSAU.

## 📌 Sobre o projeto

Sistema de agendamento para uma clínica de estética facial, com página institucional, painel administrativo e atendimento inicial automatizado por Inteligência Artificial via WhatsApp. A IA realiza a triagem do cliente e direciona o atendimento para o fluxo de agendamento direto ou para um consultor humano.

## 🚀 Tecnologias utilizadas

- [Next.js](https://nextjs.org/) (React + TypeScript)
- [Tailwind CSS](https://tailwindcss.com/)
- [Supabase](https://supabase.com/) (banco de dados e autenticação)
- API do WhatsApp + LLM (atendimento automatizado por IA)
- [Vercel](https://vercel.com/) (hospedagem/deploy)

## ⚙️ Funcionalidades principais

- Página institucional (serviços, equipe, filosofia, contato)
- Atendimento inicial via WhatsApp com IA
- Triagem e direcionamento (agendamento automático ou consultor humano)
- Painel administrativo (gestão de agendamentos, serviços e equipe)
- Histórico de atendimentos e agendamentos

## 🖥️ Como rodar o projeto localmente

```bash
git clone https://github.com/Edmilson-Dev-hub/vilar-estetica-agendamento.git
cd vilar-estetica-agendamento
npm install
npm run dev
```
